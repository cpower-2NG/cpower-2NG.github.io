AtCoder ABC452 E - You WILL Like Sigma Problem

题目与目标

给定序列 A=(A1​,…,AN​) 与 B=(B1​,…,BM​)，求

i=1∑N​j=1∑M​Ai​Bj​(imodj)(mod998244353).

下面给出完整的数学推导与算法，实现时应注意取模和整型溢出。

一、式子变换（去掉模运算）

利用恒等

imodj=i−j⌊ji​⌋,

可得

S​=i=1∑N​j=1∑M​Ai​Bj​(imodj) ​=i=1∑N​j=1∑M​Ai​Bj​(i−j⌊ji​⌋) ​=i=1∑N​Ai​ij=1∑M​Bj​−i=1∑N​Ai​j=1∑M​Bj​j⌊ji​⌋.​

把求和顺序按 j 展开也是常见做法；下面给出两种等价且常用的实现思路，重点在于如何高效计算含有 ⌊⋅⌋ 的项。

二、按 j 外层（推荐实现）——对 A 分段

我们把原式按 j 展开：令

S=j=1∑M​Bj​⋅Sj​,Sj​=i=1∑N​Ai​(imodj).

由 imodj=i−j⌊i/j⌋，得到

Sj​=可预计算一次i=1∑N​Ai​i​​−j⋅Tj​,Tj​=i=1∑N​Ai​⌊ji​⌋.

关键在于高效计算 Tj​. 观察到：对固定 j，⌊i/j⌋ 在 i 上是分段常数：当 k≥1 时

⌊i/j⌋=k⟺kj≤i≤min((k+1)j−1,N).

因此
[\displaystyle
T_j=\sum_{k=1}^{\lfloor N/j\rfloor} k \sum_{i=kj}^{\min((k+1)j-1,N)} A_i.
]

用前缀和 pref[x]=∑i=1x​Ai​, 区间和在 O(1) 内得到。于是对每个 j 遍历 k=1…⌊N/j⌋ 即可算出 Tj​。

复杂度分析：对每个 j 的时间为 O(⌊N/j⌋)，总时间

j=1∑M​O(⌊N/j⌋)=O(Nj=1∑M​j1​)=O(NlogM).

实现要点：

  • 预算好 P=∑i=1N​Ai​i(modp)（只需一次）。
  • 对每个 j：若 j>N 则 Tj​=0，且 Sj​=P；否则按上面分段计算 Tj​ 并得到 Sj​=(P−jTj​)modp。

注意取模和负数处理：每次减法后若为负须加上模 p。

三、按 i 外层——对 B 分段（另一种视角）

也可按 i 外层求

S=i=1∑N​Ai​(j=1∑M​Bj​(imodj))=i=1∑N​Ai​Ui​.

对固定 i，把 j 分成 j>i 与 j≤i 两部分：

  • 若 j>i，有 imodj=i，这部分贡献 i∑j=i+1M​Bj​；
  • 若 j≤i，使用 imodj=i−j⌊i/j⌋, 得到

[\displaystyle
\sum_{j=1}^{\min(M,i)} B_j(i\bmod j) = i\sum_{j=1}^{\min(M,i)} B_j - \sum_{j=1}^{\min(M,i)} B_j\, j\Big\lfloor\frac{i}{j}\Big\rfloor.
]

对第二项令 q=⌊i/j⌋, 则当且仅当

⌊q+1i​⌋<j≤⌊qi​⌋.

因此可以把 j 按 q 分段：
[\displaystyle
\sum_{j=1}^{\min(M,i)} B_j\, j\Big\lfloor\frac{i}{j}\Big\rfloor = \sum_{q\ge1} q \sum_{j=\lfloor i/(q+1)\rfloor+1}^{\lfloor i/q\rfloor} jB_j,
]
区间和可用前缀和 prefJB[x]=∑j=1x​jBj​ 在 O(1) 内得到。

该方法的总复杂度受每个 i 的分段数量影响，通常也可用平方根分割等技巧优化。

四、总结与实现细节

  • 推荐实现：按 j 外层、用 A 的前缀和与上面 (二) 中的分段方法，代码简洁且复杂度约 O(NlogM)。
  • 数据类型：中间乘法与累加请用 64 位整型并及时对 998244353 取模。
  • 边界：若 j>N, Tj​=0；若 A,B 很大，输入时可对模取余（若题目允许）。

五、伪代码（按 j 外层）

read N, M, A[1..N], B[1..M]
pref[0]=0; for i=1..N: pref[i]=pref[i-1]+A[i]
P = sum_{i=1..N} A[i]*i (mod p)
ans = 0
for j = 1..M:
  if j > N: S_j = P
  else:
    T = 0
    for k = 1..floor(N/j):
      l = k*j; r = min(N, (k+1)*j-1)
      seg = pref[r]-pref[l-1]
      T += k * seg (mod p)
    S_j = (P - j*T) mod p
  ans = (ans + B[j] * S_j) mod p
print ans
