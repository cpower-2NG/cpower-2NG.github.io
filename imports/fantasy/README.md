# Fantasy 内容原件整理

原始文件保存在 `imports/fantasy/raw/`。该目录被 Git 忽略，避免把 75 MB 的 Word、PDF 和图片直接推入公开仓库；文件完整性和摘要记录在 `source-manifest.json`。

完整性检查：

```powershell
node tools/verify-imports.mjs
```

不要使用 `git clean -fdx` 清理工作区，否则被忽略的 `raw/` 也会被删除。当前阶段它是下载目录之外的本地保全副本，后续会上传 Azure Blob 并建立长期备份。

## 处理原则

- 原始 DOCX 和 PDF 不进入 GitHub Pages 产物。
- PDF 保留原版排版，后续使用它生成封面和阅读入口；需要编辑时仍以 DOCX 为源。
- TXT 会先清洗编码、标题、空格和段落，再转为 Markdown 进入 `content-src/fantasy/`。
- 图片和附件摘要进入 `assets/`；大体积原件后续上传 Azure Blob。
- 所有内容公开发布前逐篇确认，不按 QQ 同步规则自动发布。
