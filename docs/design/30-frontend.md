# BIFROST 设计文档 · 前端设计

> 本文定义前端的呈现契约与交互结构。
> 数据来源与字段见 `10-data-design.md`，查询与互动接口见 `20-backend.md`。

## 目的

定义内容变多之后前端的组织方式：侧栏如何保持稳定、分区如何浏览、动态如何翻阅、查找如何组合，以及阅读页面如何消费数据。

## 范围

- 覆盖：导航结构、视图形态、查找入口、路由与数据源、渲染契约，以及现有前端实现的整理。
- 不覆盖：具体视觉样式与组件实现（本轮不动视觉）、数据模型（见 `10-data-design.md`）。

## 关键决策

### 目标契约

1. **侧栏只放结构导航**：阶段切换、分区入口与搜索入口。侧栏永不逐条展开内容，内容再多也不变形；系列以卡片形式出现在内容列表，标签不占侧栏。
2. **Logic 侧栏第一入口**：Logic 侧栏第一个入口为"展示"，即 Logic 首页（工作展示页）。
3. **分区列表形态**：文章类分区用杂志式——首篇大图打头，其余为卡片；支持筛选与分页，不做朴素文本堆叠。
4. **动态视图**：日常分区用社交动态流——无头像，正文 + 时间 + 错位叠放图片 + 视频卡片 + 评论点赞；滚动加载，数量只影响该视图分页。
5. **封面兜底**：指定封面 → 正文首图 → 文字封面（前端按标题排版生成）。
6. **不按年份分组**：分区列表不做年份分组，时间维度由分页与搜索面板的时间筛选承担。
7. **聚合页**：分类页与系列页自动生成；标签与时间不生成独立页面，由搜索面板的筛选承担（见 D-49）。
8. **双交互入口**：`~` 只呼出位面切换面板（彩蛋性质，不做检索）；`Ctrl/Cmd+K` 呼出独立搜索面板，承载关键词、组合筛选（类型 / 分类 / 标签 / 时间）与分面计数。
9. **双数据源**：
   - 阅读页面消费静态物化产物（快、SEO 好、Azure 不可用时仍可读）。
   - 查找、筛选、分面消费后端检索接口。
   - 评论、点赞、阅读数消费互动接口。
10. **路由**：以可读 slug 呈现，以 `entryId` 定位；旧地址由后端 `routes` 重定向。
11. **来源不外露**：前端不展示内容来源（上传 / QQ / 导入），该信息只存在于管理侧。

### 视图与数据来源

| 视图 | 数据来源 |
|---|---|
| 阅读页（文章 / 动态） | 静态物化产物 |
| 分区列表（杂志式） | 检索接口（筛选 phase + section） |
| 日常动态流 | 静态产物或按月查询 |
| 搜索面板（关键词 + 筛选 + 分面） | 检索接口 + 分面 |
| 位面切换面板 | 本地相位状态 |
| 系列页（默认显示第一篇） | 系列实体 + 检索接口 + 静态产物 |
| 分类页 | 检索接口 + 分类法 |
| 互动区 | 互动接口 |
| 侧栏结构 | 分类法 + 静态物化产物 |

### 现状（现有实现参考）

以下为当前站点已经落地的实现，是迁移起点，不代表目标架构。

**壳层与引擎**

- 单页容器：`index.html` 承载骨架，`core/engine.js` 负责路由拦截、内容加载、目录渲染、状态管理与主题切换。
- 无刷新导航：目录点击拦截后按需 `fetch` 内容片段并注入主内容区。
- 状态恢复：相位、最近文章路径与阅读滚动位置保存在 LocalStorage，回访自动恢复并跳过启动动画。
- 目录高亮：当前文章在侧栏目录中带激活标记。

**相位系统**

- Logic 为"冷档案 HUD"，Fantasy 为"文库本手记"，两套视觉语义共享同一信息架构。
- 命令面板支持 `logic` / `fantasy` 切换，切换时清理旧相位路径记录；色彩、字体与入场动效同步过渡。
- 相位切换光桥：一道目标相位色光带扫过全屏，扫过中点完成提交；`prefers-reduced-motion` 下直接切换。

**阅读体验**

- 内容模型条目包含 `section`、`kind`、`layout`、`source`、`publication` 与 `video`。
- 文章页自动注入日期 / 类型 / 阅读时长 / 标签元信息行与上一篇、下一篇导航。
- 阅读版式：正文约 `42em` 版心、17px 字号、1.8 行高；`note`、`event`、`longform`、`publication` 四套数据驱动版式。
- 阅读边缘栏（`≥1200px`）：进度线、日期 / 时长 / 分类、标签与回到顶部。
- 数学公式：正文公式在物化时预渲染为 KaTeX HTML，CSS 与字体随站点发布（`core/katex/`），不引入运行时脚本；宽公式横向滚动不撑破版心。
- 图片预览：正文图片点击后使用原生 `<dialog>` 放大，支持键盘、遮罩、缩放与拖动。
- PDF 出版物：支持普通正文排入与横向对页阅读器，并提供下载。
- 深链修复：`content/` 下的文档自带引导脚本，直接访问会重定向回 SPA 的正确相位。
- 窄屏导航（`≤960px`）：侧栏默认收起，点页头"目录"展开。

**中文排版约束**

- 标题与正文用 `em` 控制行宽，不使用 `ch`。
- 标题 `text-wrap: balance`、正文 `text-wrap: pretty`，并设 `line-break: strict`。

**环境音（`core/ambience.js`）**

- 按相位程序化生成，不依赖音频素材文件；Logic 为低频嗡鸣，Fantasy 为风声与五声音阶铃声。
- 默认静音，首次点击开关后才创建 AudioContext，偏好写入 LocalStorage。

**互动**

- 评论、一层回复、点赞与阅读数由 `data/site.json` 的 `interactions` 接入后端。
- 昵称可留空并明确选择匿名；邮箱与个人网站可选。
- 后端不可用时互动块整体移除，不留下空壳，正文保持完整可读。

## 接口与契约

- **静态产物契约**：阅读页面只依赖物化产物，不依赖运行时服务。
- **检索契约**：筛选与分面字段以 `10-data-design.md` 的检索投影字段为准，前端不自定义字段名。
- **路由契约**：对外地址使用 slug，内部定位使用 entryId；旧地址重定向由后端负责。
- **降级契约**：检索或互动不可用时，阅读功能不受影响；相关区块整体隐藏而不是显示空壳。
- **配置契约**：站点地址与互动服务地址来自 `data/site.json`。
